Privacy Policy

Hermes Workspace — last updated 1 October 2026

Summary

Hermes Workspace is a single-user, self-hosted integration. It accesses the Google data of one Google Account: the developer's own. There are no other users, no accounts to create, and no data is sold, published or shared.

Data accessed

With the account holder's explicit consent, the integration requests these Google API scopes:

  • Gmail (gmail.modify, gmail.settings.basic, gmail.settings.sharing) — reading, searching and labelling the account's own mail
  • Google Drive (drive) — reading, creating, uploading, moving and renaming files in the account's own Drive
  • Google Calendar (calendar) — reading and managing the account's own calendars and events
  • Google Sheets, Docs and Slides (spreadsheets, documents, presentations) — reading and updating the account's own files
  • Google Tasks (tasks) — reading and managing the account's own task lists
  • Contacts and directory (contacts, contacts.other.readonly, directory.readonly) — resolving names of people and organisations
  • Google Forms (forms.body, forms.responses.readonly) — reading the account's own forms and responses
  • Google Chat and Classroom — reading the account's own spaces, messages and course data, where present
  • Apps Script (script.projects, script.deployments, script.processes) — managing the account's own scripts
  • Basic profile (userinfo.email, userinfo.profile, openid) — identifying the connected account

Some of these scopes allow writing, because the integration files documents, updates spreadsheets, manages tasks and organises Drive folders on the account holder's instruction. Every scope is used solely against the consenting account's own data.

How the data is used

Solely for the account holder's own personal productivity: producing a daily briefing of mail and calendar, maintaining personal task lists, filing and organising the account's own documents, and generating reports from the account's own spreadsheets. The data is not used for advertising, profiling, resale, or any commercial purpose, and is not used by the developer to train or improve machine-learning models.

Storage, processing and retention

Data is stored and processed on a private, self-hosted server controlled by the account holder. OAuth credentials are kept on that server and access is restricted to the account holder. Some content is summarised with the assistance of third-party AI language-model services in order to generate the daily briefing; that processing is limited to producing the account holder's own summary, and the data is not sold, published or shared with any other party. Derived summaries and any local caches are retained only for as long as they are useful, and can be deleted by the account holder at any time.

Sharing

No Google user data is sold, rented, published or disclosed to third parties, and none is used for advertising or to determine creditworthiness or for lending purposes. There is no advertising, analytics or tracking on this website. Data is transferred between Google and the integration over encrypted connections (HTTPS/TLS).

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Revoking immediately removes the integration's ability to read or write any further data, and locally stored copies can then be deleted on request.

Google API Services User Data Policy

Hermes Workspace's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Changes and contact

Any change to this policy will be published on this page. Questions about this policy or about data handling can be sent to benjolisto@gmail.com.
